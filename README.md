# 📚 StudyDocShare - Nền Tảng Chia Sẻ Tài Liệu Học Tập (Client-Server Socket)

**StudyDocShare** là ứng dụng chia sẻ tài liệu học tập dành cho sinh viên, được phát triển theo mô hình **Client-Server** giao tiếp qua **TCP Socket nguyên bản** và giao diện đồ họa **CustomTkinter**.

---

## 🚀 HƯỚNG DẪN KHỞI CHẠY TRỰC TIẾP (QUICK START)

### 1. Yêu cầu hệ thống
- **Python**: Phiên bản 3.10 trở lên
- **Hệ điều hành**: Windows, macOS, hoặc Linux

### 2. Cài đặt thư viện phụ thuộc
Mở Terminal / Command Prompt tại thư mục gốc của dự án (`StudyDocShare/`) và chạy lệnh:
```bash
pip install -r requirements.txt
